# Pinecone Studio Web webpage

This repository hosts the public webpages, assets, and privacy policy for **Pinecone Studio**, an elegant visual manager and VS Code companion for Pinecone vector databases.

## Public folder items

All public assets are located in the [public/](public/) directory:

- [public/favicon.svg](public/favicon.svg): Stylized site favicon.
- [public/pinecone-studio-logo.svg](public/pinecone-studio-logo.svg): Dark-themed high resolution SVG vector logo.
- [public/webpage/index.html](public/webpage/index.html): Studio plugin home page, highlighting features and links for VS Code, Web apps, and Docker pulls.
- [public/webpage/theme.css](public/webpage/theme.css): Beautiful dark cosmic style theme definitions.
- [public/policy/privacy.html](public/policy/privacy.html): Compliant privacy policy detailing data flows.

## Configuration & Deployment

Publish files inside `public` directly to secure developer hubs, plugin gateways (VS Code Marketplace, Open VSX), or deploy directly on GitHub Pages!
